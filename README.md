# Helmet Swapper — releases

Installer and update files for **Helmet Swapper** by RM Designs Studio.

**Install:** download `RMDesigns.HelmetSwapper-win-Setup.exe` from the latest release and run it once.
After that the app updates itself: when a new version is out, an **UPDATE** box appears next to the version number in the app — click it and the app restarts on the new version.

This repo holds release files only.
